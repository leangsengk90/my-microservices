What it does

The single source of truth for user data

Profile data lives in one place, so a change shows up the same way everywhere.

🪪

Rich profiles

Name, avatar, bio, location, links and skills, all in one record.

⚙️

Preferences

Language, theme and notification settings that follow the user across apps.

🔒

Privacy controls

Users choose which fields are public, visible to friends, or private.

📈

Completeness score

Suggests what to fill in next to complete the profile.
