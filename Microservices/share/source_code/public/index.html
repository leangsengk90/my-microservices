What it does

File sharing without the friction

Drop files in, get links out, and choose how long they stay available and who can see them.

🔗

Instant links

Every upload gets a short, unique link you can copy right away.

⏳

Expiring shares

Links can expire after a set time or after a number of downloads.

👁️

Access control

Choose public, team-only or password-protected for each file.

📦

Any file type

Documents, images, archives: anything up to the size limit.
